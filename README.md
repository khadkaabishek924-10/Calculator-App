# Simple Calculator & Calculation History

A beginner-friendly Calculator Web Application built with:

- React.js
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Lucide React
- LocalStorage

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Decimal numbers
- AC
- DEL
- Division-by-zero handling
- Calculation history
- Individual history deletion
- Clear all history
- LocalStorage persistence
- Responsive design

## Routes

- `/calculator`
- `/history`

`/` redirects to `/calculator`.

## Installation

```bash
npm install
```

## Run

```bash
npm run dev
```

## Build

```bash
npm run build
```

## LocalStorage

History is saved using:

```text
calculator_history
```

No backend or database is required.
